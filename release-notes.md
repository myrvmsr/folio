Folio est maintenant disponible sur **Windows et Linux**.

Téléchargez le fichier correspondant à votre ordinateur :

- **Windows 64 bits** : `Folio-Setup.exe`.
- **Ubuntu / Debian 64 bits** : `Folio-Linux-x64.deb`.
- **Autres distributions Linux 64 bits** : `Folio-Linux-x64.AppImage` (autoriser son exécution avant de l’ouvrir).

Folio prend en charge l’ouverture depuis les gestionnaires de fichiers Linux et distingue les fichiers dont seule la casse diffère sur les systèmes qui le permettent.

Les trois installateurs ont été compilés et vérifiés sur leur système : Windows et Ubuntu 24.04. Les contrôles incluent l’installation ou l’exécution du paquet, le démarrage, le rendu Markdown, les formules, les diagrammes, l’édition, l’enregistrement automatique, les opérations et la surveillance des dossiers, ainsi que la génération de PDF.

Pour mettre à jour, fermez Folio puis installez la nouvelle version par-dessus l’ancienne. Vos réglages et vos documents sont conservés. [Instructions complètes](https://github.com/myrvmsr/folio).
